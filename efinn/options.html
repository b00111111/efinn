⚠ CORS blocked (403 Forbidden) — Ollama is rejecting POST requests from this extension. Chrome extensions send an Origin header that Ollama blocks by default.

Fix: restart Ollama with this environment variable set: 
Mac / Linux:
  OLLAMA_ORIGINS="chrome-extension://*" ollama serve
Windows (PowerShell):
  $env:OLLAMA_ORIGINS="chrome-extension://*"; ollama serve
To set it permanently, add OLLAMA_ORIGINS=chrome-extension://* to your shell profile (~/.zshrc, ~/.bashrc) or Windows system environment variables, then restart Ollama.

After restarting Ollama, click Test Connection again.
