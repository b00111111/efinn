# Connecting GitHub to Claude (Cowork)

Your engineering plugin already includes the GitHub connector — it just needs to be authorized via OAuth.

## Steps

1. Open **Settings** in the Claude desktop app
2. Navigate to the **Integrations** or **MCP** section
3. Find **GitHub** under your engineering plugin and click **Connect**
4. Your browser will open GitHub — approve the authorization request
5. Return to Claude — the GitHub tools will now be active in your session

## What you'll be able to do once connected

- Create, view, and merge pull requests
- Browse issues and repositories
- Push code changes and manage branches
- Review diffs and file contents directly from chat

## Troubleshooting

If the Connect button doesn't appear, try typing `/mcp` in the Claude chat input to open the MCP panel directly.
